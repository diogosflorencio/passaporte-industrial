Projeto simples para se conectar ao Passaporte Industrial Findes e fazer extração de dados de forma mais precisa e em planilhas organizadas, favorecendo e facilitando o trabalho da segurança do trabalho de empresas na Samarco. O projeto não modifica em nada o sistema Findes e apenas utiliza os endpoints para extração de dados, além de usar um único POST para autenticação conforme as credenciais do usuário padrão.
